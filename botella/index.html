    Cómo se juega

    1. Cargá los nombres. De 2 a 12 personas. Se guardan en este dispositivo para la próxima.
    2. Elegí la intensidad. Suave para arrancar, Media para soltarse y Picante para cuando ya hay confianza.
    3. Girá la botella. La rueda elige a quién le toca y saca una pregunta del mazo.
    4. Respondé en voz alta. Si no querés, pasá: nadie está obligado a contestar nada.

    Las preguntas no se repiten hasta que se termina el mazo de esa intensidad. Después se mezclan de nuevo. No hay puntos ni ganadores: es para hablar.
